**إنجاز** هو تطبيق محمول مصمم لمساعدتك على بناء العادات الإيجابية والاستمرار فيها يومياً بأسلوب يركز على الهدوء الرقمي والإنتاجية الحقيقية بعيداً عن التشتيت.

يعمل التطبيق بمبدأ **الخصوصية أولاً (100% Offline-First)**؛ حيث تُحفظ كافة بياناتك محلياً على جهازك دون الحاجة إلى إنترنت، ودون أي إعلانات أو تتبع أو متطلبات تسجيل دخول، مع دعم كامل وأصيل للغة العربية.

## 🌟 أبرز المميزات

### 🌿 1. تجربة هادئة ومريحة
* **تركيز كامل على العادات:** واجهات مريحة للعين بألوان ترابية محايدة وتصميم بصري متزن يساعدك على التركيز.
* **بيئة نقية من التشتيت:** خلو تام من الإعلانات، النوافذ المنبثقة، أو أي عناصر بصرية مزعجة.
* **مؤثر صوتي مريح:** تغذية صوتية خافتة ومريحة عند إتمام العادة تعزز شعور الإنجاز والرضا (يمكن تفعيلها أو كتمها بلمسة واحدة من الإعدادات).
* **دعم الوضع الداكن والفاتح:** تباين ناعم ومدروس يحترم إعدادات نظام التشغيل مع إمكانية التحديد اليدوي.
* **سلاسة تامة وسرعة استجابة:** تجربة تمرير فائقة الانسيابية واستجابة فورية حتى مع وجود مئات العادات والسجلات.

### 🎯 2. إدارة مرنة ومتطورة للعادات
* **عادات كمية ونوعية:**
  * عادات نوعية بسيطة (نعم / لا) كالقراءة والأذكار.
  * عادات كمية بأهداف قابلة للقياس ووحدات مخصصة (دقيقة، لتر، صفحة، ركعة، كوب...).
* **أنماط تكرار متعددة:**
  * يومي.
  * أيام محددة من الأسبوع.
  * هدف بعدد المرات أسبوعياً (مثلاً: 3 مرات في الأسبوع).
  * يوم محدد من الشهر (مثلاً: اليوم الأول من كل شهر).
  * هدف بعدد المرات شهرياً.
* **مسودات تلقائية ذكية:** حفظ فوري لمدخلات العادة تلقائياً لتفادي ضياع بياناتك عند المقاطعة أو الخروج المفاجئ.
* **تثبيت وإعادة ترتيب:** إمكانية تثبيت العادات المهمة في القمة وإعادة ترتيبها يدوياً أو أبجدياً.
* **إجراءات سريعة:** مضاعفة العادات، التعديل، أو الأرشفة بلمسة واحدة.

### 📅 3. تتبع تفاعلي ويوميات إنجاز
* **شريط التاريخ التفاعلي:** تنقل سلس وفوري بين الأيام لتسجيل أو استدراك العادات السابقة بسهولة.
* **مؤشر التقدم اليومي:** بطاقة ملخصة تعرض نسبة إنجاز أهداف اليوم بوضوح وبساطة دون تعقيد.
* **يوميات وتأملات الإنجاز:** تدوين ملاحظة أو فكرة مرافقة لكل إنجاز، مع إمكانية استعراض أرشيف التأملات في أي وقت.

### 📊 4. إحصائيات عميقة وتحليلات الاستمرارية
* **سلاسل الاستمرارية (Streaks):** حساب دقيق للسلسلة الحالية وأفضل إنجاز تاريخي يدعم استمرارية طويلة تمتد لأكثر من عام دون انقطاع.
* **الخريطة الحرارية والتقويم الشهري:** تقويم بصري تفاعلي يتيح مراجعة الأيام المنجزة وتعديل السجل تاريخياً باللمس المباشر.
* **محطات الإنجاز التقديرية:** أوسمة تقديرية رصينة عند إتمام 7 أيام، 21 يوماً، 30 يوماً، 100 يوم، وسنة كاملة (365 يوماً).
* **تحليل توازن العادات:** قياس نسبة التوازن بين مجالات الحياة المختلفة (صحة، عبادة، تطوير، إنتاجية).
* **مشاركة الإنجاز:** إمكانية تصدير ملخص إنجاز العادة بنص عربي أنيق وبليغ لمشاركته مع الآخرين.

### 🔒 5. خصوصية مطلقة ونسخ احتياطي محلي
* **محلي بالكامل (100% Offline-First):** بياناتك ملكك وحدك، مشفرة ومحفوظة داخل جهازك دون أي خوادم أو اتصال بالإنترنت.
* **بدون حسابات:** لا يتطلب التطبيق إنشاء أي حساب أو إدخال بريد إلكتروني أو أي بيانات شخصية.
* **نسخ احتياطي واستعادة محلية:** تصدير واستيراد نسخة احتياطية كاملة بصيغة (JSON) على جهازك في أي وقت.
* **تصدير تقارير إكسل (CSV):** تصدير سجل الإنجازات وملخص العادات إلى ملفات CSV بترميز خاص يدعم فتح النصوص باللغة العربية بوضوح تام في Microsoft Excel.

### 🌐 6. أصالة لغوية عربية (Arabic-First)
* **قواعد النحو والعدد:** صياغة لغوية دقيقة للسلاسل والإحصائيات تراعي قواعد المفرد والمثنى وجمع القلة وتمييز الأعداد.
* **محرك بحث ذكي:** تطبيع متقدم للنصوص العربية (مطابقة مرنة تدمج أشكال الهمزة `أ/إ/آ/ا`، والتاء المربوطة والهاء `ة/ه`، وتتجاهل علامات التشكيل).
* **أرقام عربية ومشرقية:** توافق مرن مع الأرقام العربية والمشرقية واتجاه الكتابة من اليمين إلى اليسار (RTL).

### 🔔 7. تنبيهات وتذكيرات ذكية
* تذكيرات محلية مجدولة بدقة لكل عادة بحسب أوقاتها وأيامها المحددة.
* تنبيه المراجعة والتأمل المسائي لمتابعة ما تحقق خلال اليوم بهدوء قبل النوم.

## 🚀 البدء والتشغيل (Getting Started)

### المتطلبات الأساسية
* **Node.js**: الإصدار `20.x` أو أحدث.
* **npm** أو **yarn** أو **pnpm**.
* تطبيق **Expo Go** على هاتفك الذكي، أو محاكي Android Studio / Xcode.

### 1. استنساخ المشروع وتثبيت الاعتماديات:
```bash
git clone https://github.com/sultanAlhabsi/enjaz-Habit-Tracker.git
cd enjaz-Habit-Tracker
npm install
```

### 2. تشغيل خادم التطوير:
```bash
npx expo start
```
* اضغط `a` لفتح التطبيق على محاكي **Android**.
* اضغط `i` لفتح التطبيق على محاكي **iOS**.
* امسح رمز الاستجابة السريعة (QR Code) عبر كاميرا الهاتف أو تطبيق **Expo Go**.

### 3. تشغيل النفق (Tunnel) للتجربة عن بعد:
إذا كنت تواجه مشاكل في الاتصال بشبكة الـ Wi-Fi المحلية:
```bash
npm run tunnel
```

## 🛡️ الأمان والجاهزية للإنتاج (Production & Security)

* **تقليص الحجم والتشفير (Android R8 & ProGuard):** تم ضبط `app.config.js` لتمكين `minifyEnabled` و `shrinkResources` في إصدارات الإنتاج مع قواعد ProGuard صارمة لمكتبات Reanimated و SQLite.
* **أحدث مستويات أندرويد:** متوافق مع `targetSdkVersion 36` و `compileSdkVersion 36`.
* **أمان وخصوصية البيانات:** تشغيل محلي بالكامل دون إرسال أي بايت من البيانات لأي خوادم خارجية.
